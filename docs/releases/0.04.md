# 🚀 KUI 0.04 — Kotlin-only release

**Tag:** `v0.04` · **CLI/package version:** `0.4.0` · **Status:** experimental

## Highlights

- Kotlin implements the CLI, compiler orchestration, DEX, binary manifests, APK alignment, v2 signing/verification, JVM tests, and ADB commands.
- Removed the Rust workspace, native CLI, and checked-in hybrid installers.
- Added executable project tests, failure handling, and a runner for all repository suites.
- Preserved literal background colors, contrast text, and alignment in the generated Android text Activity.
- Refreshed documentation with a beginner learning path, verified examples, and a developer experience proposal.
- Release packaging derives its version from the CLI and validates distributed launchers and checksums.

## Downloads

- `kui-0.4.0-windows.zip`: portable Windows package.
- `kui-0.4.0-windows-x64.msi`: Windows installer with PATH registration.
- `hello-0.4.0-debug.apk`: signed greeting APK for evaluation; debug signing only.
- Matching `.sha256` files: download integrity checksums.

Application builders need Kotlin 2.0+ and JDK 21+. Standalone ADB platform-tools are required for automatic phone deployment. A full Android SDK is unnecessary. APK users do not need the development tools.

## Validation

The release workflow runs all Kotlin suites, builds a sample APK, creates ZIP/MSI packages, verifies their checksums and versions, and publishes only after those checks pass. The repository's full suite comprises 18 test programs and 575 checks. Documentation includes 21 complete compiled examples and executable state/render checks.

## Current limitations

The Android backend generates a native text Activity from literal source content. General JVM-to-DEX translation and complete interactive UI4 Android hosting are incomplete. The JVM framework's layout, state, input, and rendering tests do not establish on-device feature parity.

Device profiling, JUnit discovery, a production release-signing workflow, and UI4 Android image/font rendering are not implemented. A generated greeting APK was installed and launched on a TECNO BG7 during release verification, with the expected text confirmed in the device UI. This is a text Activity smoke check, not full interactive runtime coverage.
