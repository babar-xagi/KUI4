# KUI user guide

KUI builds APKs using Kotlin and JDK 21+. Install standalone ADB platform-tools if you want KUI to install and launch apps on a phone. No full Android SDK installation is required.

- [Getting started](getting-started.md)
- [CLI reference](cli-reference.md)
- [Project guide](project-guide.md)
- [UI components](ui-components-and-styling.md)
- [Examples](cookbook-and-examples.md)
- [Troubleshooting](troubleshooting.md)

The Android backend currently displays literal UI text in a generated native Activity. JVM UI4 features, including reactive state and input, are not yet fully connected to the Android host.
