# 👋 Build with KUI

You write application code in Kotlin using UI4. KUI handles compilation, APK packaging, signing, and device commands.

## 📱 Know the current scope

Kotlin 2.0+ and JDK 21+ are required on the build computer. Standalone ADB platform-tools are needed for automatic device deployment. A full Android SDK installation is unnecessary.

The generated Android Activity displays extracted literal text and supported literal styling. Interactive UI4 examples demonstrate JVM framework behavior until the Android host and DEX translator are complete. An end user receiving an APK does not need the development tools.
