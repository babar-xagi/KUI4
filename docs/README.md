## 🧭 How to read these guides

**KUI** is the Kotlin toolchain. **UI4** is the declarative UI framework.

Application examples build UI trees on the JVM. The current Android backend generates a text Activity; complete interactive UI4 Android hosting is still in development. The [support table](../README.md#-what-works-today) describes the distinction.

The current guides describe implemented behavior. The [platform roadmap](../UI4_KUI_PURE_KOTLIN_PLATFORM_ROADMAP.md), [milestone reports](reports/), and historical changelog entries describe plans or past verification, not guarantees about today's Android output.
