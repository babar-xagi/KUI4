# 📚 KUI Documentation Portal

Welcome to the **KUI Documentation**! Whether you are building an application with KUI or contributing to the core compiler and UI engine, you will find comprehensive guides here.

## 🧭 Navigation

### 👤 [User Documentation (`docs/user/`)](user/README.md)
Everything you need to install KUI, create projects, build APKs, and run them on Android devices:
* **[🚀 Getting Started](user/getting-started.md):** System requirements, MSI installation, and your first app.
* **[💻 CLI Reference](user/cli-reference.md):** Complete guide to all 10 native `kui` commands.
* **[📁 Project Guide](user/project-guide.md):** Directory structure, `kui.toml` configuration, assets, and builds.
* **[🎨 UI Components & Styling](user/ui-components-and-styling.md):** Guide to building declarative user interfaces with UI4.
* **[📖 Cookbook & Examples](user/cookbook-and-examples.md):** Real-world recipes and sample apps.
* **[🩺 Troubleshooting](user/troubleshooting.md):** Solutions to common issues, ADB setup, and runtime crashes.

### 🛠️ [Developer Documentation (`docs/developer/`)](developer/README.md)
Deep dive into the dual-layer architecture, native Rust crates, Dalvik compiler, and contribution guidelines:
* **[🏗️ Architecture & Pipeline](developer/architecture.md):** End-to-end build pipeline, data flow, and technology choices.
* **[🗂️ Directory Structure Reference](developer/directory-structure.md):** File-by-file map of the workspace.
* **[⚙️ kui-dex Internals](developer/kui-dex-internals.md):** Dalvik bytecode translation, MUTF-8 surrogate encoding, and ART verification.
* **[🎨 UI4 Engine Architecture](developer/ui4-engine.md):** 2-pass layout, dirty tracking, and canvas rendering.
* **[🤝 Contributing Guide](developer/contributing.md):** Local setup, running `cargo test`, building MSI installers, and PR workflow.
