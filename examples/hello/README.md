# 👋 Hello UI4

A starter UI4 greeting project. The current Android backend extracts the literal greeting into a generated native text Activity.

From this directory:

```powershell
..\..\kui.bat build
..\..\kui.bat run
```

Building needs Kotlin 2.0+ and JDK 21+. Running on a phone additionally needs ADB and an authorized device.

The starter AppTest is a placeholder; add actual checks before using its success message as verification.
